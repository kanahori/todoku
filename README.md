# hackathon2026 (working title)

An Electron app for Mac and Windows that lets blind and low-vision users operate web apps through a simple card interface.

Built during Built with Claude: Japan 2026 (2026-11-02 – 2026-11-08). Work in progress.

## 日本語

視覚に障害のある方が、カードの簡単な画面からウェブアプリを使えるようにする Mac・Windows のアプリ（Electron）です。開発中です。
